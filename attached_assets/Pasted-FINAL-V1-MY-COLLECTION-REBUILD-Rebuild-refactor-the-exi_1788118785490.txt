FINAL V1 MY COLLECTION REBUILD

Rebuild/refactor the existing PinHunt My Collection UI into the final V1 experience.

This is intended to be the LAST significant Collection UI rebuild before launch, so prioritise getting the interaction model, usability and polish right.

However, be very conscious of tokens and implementation cost.

FIRST inspect the existing Collection implementation and REUSE working components, backend logic, Boards, catalogue sets, pin grids, Traders, ISO, search, valuation and Pin Detail.

Do not rebuild working systems unnecessarily.

==================================================
CORE UX REFERENCE
==================================================

Use the simple, familiar interaction pattern of leading pin-collection apps as the structural inspiration:

- one obvious Collection screen
- one row of primary collection categories
- image-first Boards
- very little UI before content
- simple stats
- search/add immediately accessible

Do NOT visually copy another app.

Keep PinHunt's own brand, colours, typography and visual identity.

PinHunt's key improvement should be combining:

1. simple collector-created Boards
2. intelligent catalogue-driven Sets
3. Traders
4. ISO

The experience must remain usable for collectors with 20 pins or 2,000+ pins.

==================================================
FINAL NAVIGATION
==================================================

Remove the current multi-layer navigation:

Collection | Traders | ISO

followed by:

All Pins | Boards | Sets

Do NOT replace it with another nested navigation structure.

Instead use ONE primary tab row:

**Boards | Sets | Traders | ISO**

Default = **Boards**

This is the only permanent category navigation required on My Collection.

Do NOT include All Pins as a primary tab.

Do NOT land users on a giant grid containing every pin they own.

Do NOT automatically create an "All Pins" Board.

If users need to access every owned pin, make **View All Owned Pins** a secondary utility accessible through search/filter/overflow.

==================================================
PAGE HEADER
==================================================

Use a simple header:

**My Collection**                         Search   Add

Search and Add can be compact icons/buttons but MUST have large accessible touch targets.

Avoid a large search bar permanently consuming vertical space if an icon-triggered search experience already exists or can reuse the existing search component cleanly.

Directly underneath:

**Boards | Sets | Traders | ISO**

Then show contextual statistics for the selected tab.

Example Boards:

24 Pins        6 Boards        £420
Owned                         Est. Value

Example Sets:

24 Pins        6 Sets          2 Complete

Example Traders:

8 Traders                     £145 Est. Value

Example ISO:

12 ISO                        4 Matches

Keep these statistics lightweight.

Do not place each statistic inside a large dashboard card.

==================================================
BOARDS — DEFAULT EXPERIENCE
==================================================

Boards is the default My Collection experience.

Boards are collector-created organisation.

Examples:

Disney Traders
Winnie the Pooh
Stitch
Halloween
Favourite Pins
Disneyland Paris
Never Trade
Main Pin Board

Display Boards using a compact image-first grid.

Each Board should visually preview approximately 4 pins where enough pins exist.

Think of a simple 2x2 pin preview within the Board card.

Below the preview show:

Board Name

X Pins | £Estimated Value

Only show estimated value if existing valuation data makes this straightforward.

Keep cards compact enough to comfortably show two Boards across on normal mobile screens.

Tapping anywhere on the Board card should open it.

Do NOT require users to precisely tap the Board name or another tiny control.

Inside a Board, show its pins using the existing pin grid.

Support existing Board management:

- Create Board
- Rename
- Add pins
- Remove pins
- Delete
- Open

A pin can belong to multiple Boards without duplicating the underlying ownership record.

Reuse existing Board/custom Collection functionality.

==================================================
SETS — AUTOMATIC PINHUNT ORGANISATION
==================================================

Sets are NOT manually-created Boards.

Sets are automatically organised by PinHunt using catalogue metadata.

If a collector owns ANY pin belonging to a recognised official catalogue Set, that Set should automatically appear under Sets.

NO manual "Track Set" step is required.

Example:

Collector adds one Princess Pastries 2024 pin.

Catalogue says it belongs to an 8-pin set.

Sets automatically shows:

Princess Pastries 2024
1 / 8 collected

Add another:

2 / 8

Remove one:

1 / 8

Progress must derive dynamically from actual ownership + catalogue set membership.

Do not create duplicate/manual progress records that can become inconsistent.

==================================================
SETS SCREEN
==================================================

Display Sets using similarly compact, visual cards so moving between Boards and Sets feels consistent.

Each Set card should show:

- representative pin previews/set image
- Set name
- owned / total
- completion percentage or simple progress
- Complete ✓ when finished

Example:

Wishables Shimmer 2026
12 / 16 · 75%

Ducks of Disney 2025
16 / 16 · Complete ✓

Do NOT permanently display another navigation row:

All | In Progress | Completed

This creates too many controls.

Instead show all relevant Sets by default.

Put:

- In Progress
- Completed
- Completion %
- Name/year sorting

inside ONE Filter/Sort control.

Optionally provide a subtle Browse Sets action for discovering catalogue sets the collector hasn't started.

Do not require tracking.

==================================================
SEARCH
==================================================

Search is important but should not permanently consume excessive screen space.

Use a clear Search icon/action in the header.

When activated, search the relevant Collection context.

For Boards/owned collection search, support existing metadata where available:

- Pin name
- Character
- Set/Series
- Location/Park
- Year
- Brand
- Edition type

Search results can show individual pins using the existing pin grid.

This provides a natural way to find an individual pin without making All Pins the landing experience.

Do not build AI search.

==================================================
TOUCH TARGETS / MOBILE USABILITY — IMPORTANT
==================================================

The current Collection UI contains several controls that are physically too small and difficult to tap.

Review ALL interactive controls on the Collection experience.

Every interactive control should have a minimum practical touch target of approximately:

**44px × 44px**

This includes:

- Search
- Add
- tabs
- grid/list toggle
- Filter/Sort
- back buttons
- overflow menus
- Board actions
- Set actions
- pin actions

The visible icon itself can remain approximately 20–24px where visually appropriate.

The TOUCHABLE AREA should be at least ~44px.

Do not make every control visually huge.

Use invisible padding/hit areas around compact icons where appropriate.

Tabs such as:

Boards | Sets | Traders | ISO

should each have generous horizontal and vertical tap areas.

The user should never need precision tapping.

Avoid tiny pills such as the current:

All | In Progress | Completed

row.

Avoid placing multiple tiny controls immediately beside each other without adequate spacing.

Make the entire Board/Set/pin card tappable where appropriate instead of requiring users to hit text or a small icon.

==================================================
VERTICAL SPACE
==================================================

Reduce the amount of UI users must pass before seeing their collection.

Aim for:

My Collection + Search/Add

Boards | Sets | Traders | ISO

Contextual stats

Small view/sort controls if required

CONTENT

Do not add another navigation row underneath.

On a normal iPhone, users should see meaningful Board/Set content without needing to scroll past lots of controls first.
