I want you to build an eBay catalogue validation tool for the existing PinHunt pin database.

The purpose is to identify errors in the spreadsheet data we imported, including incorrect pin names, characters, years, edition sizes, collections, duplicates and speculative records.

Do not automatically overwrite the existing pin catalogue. All eBay findings must be stored as suggestions and reviewed by an admin before any changes are applied.

Existing setup

* The app uses Supabase.
* The pin catalogue has already been imported from a spreadsheet.
* eBay API credentials are already configured.
* Use the official eBay Browse API.
* Do not scrape eBay pages.
* Use active eBay listings for validation.
* Do not claim that active listing prices are sold prices.

Search query generation

For each pin, build a focused eBay search query using the most reliable available fields:

* Pin name
* Character
* Collection or series
* Release year
* Edition size
* Release location
* Brand or manufacturer
* SKU or product ID, where present

Do not include blank, uncertain or obviously generic fields.

Generate several search variations where useful. For example:

1. Exact pin name
2. Character + collection + year
3. Character + edition size + Disney pin
4. SKU or product ID
5. Shortened title with unnecessary words removed

Avoid overly long searches that return no results.

Candidate matching

Retrieve the top matching listings for each catalogue record.

Keep the best 3 candidates for admin review.

Compare each eBay candidate against the existing record using:

* Pin-name similarity
* Character match
* Collection or series match
* Year match
* Edition size match
* Limited Edition or Limited Release match
* Release-location match
* Manufacturer match
* SKU or product-ID match
* Image similarity, if technically available
* Agreement across multiple independent listings

Do not assume the first eBay result is correct.

Confidence scoring

Create a confidence score from 0 to 100.

Use approximately this weighting:

* Strong pin-name similarity: up to 25 points
* Character match: up to 20 points
* Collection or series match: up to 15 points
* Edition size match: up to 15 points
* Year match: up to 10 points
* Release-location match: up to 5 points
* Manufacturer match: up to 5 points
* Multiple listings agreeing: up to 5 points

Apply penalties such as:

* Wrong character: minus 35
* Conflicting edition size: minus 25
* Conflicting year: minus 15
* Fantasy or custom pin: minus 40
* Pin lot or bundle: minus 25
* Clearly different artwork: minus 40
* Unrelated product type: minus 50

Use these classifications:

* 85–100: Strong match
* 70–84: Probable match
* 50–69: Needs admin review
* Below 50: No reliable match

A strong match should normally require agreement from at least two independent listings, unless there is an exact SKU or product-ID match.

Detect likely spreadsheet errors

Flag records where eBay evidence suggests:

* Incorrect pin name
* Incorrect character
* Incorrect year
* Incorrect edition size
* Incorrect limited-edition status
* Incorrect release location
* Incorrect collection or series
* Incorrect manufacturer
* Possible duplicate catalogue record
* Pin may not exist
* Record may describe a set rather than an individual pin
* Record may describe an individual pin rather than a full set
* Record may be fantasy, custom or unofficial
* Existing image may show a different pin
* Existing title is too vague to identify reliably

For every flag, provide a clear explanation.

Example:

“Existing record says LE 500, but four matching eBay listings consistently describe the pin as LE 1,000.”

Do not state that eBay proves the correction. Use wording such as:

“eBay evidence suggests…”
