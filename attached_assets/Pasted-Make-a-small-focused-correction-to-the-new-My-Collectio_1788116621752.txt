Make a small, focused correction to the new My Collection experience. Do not redesign or rebuild Collection from scratch. Reuse the components, data and styling already created in the previous Collection redesign.

The goal is to combine the best of the Pin Trading App pattern for personal organisation with the Pin Vault pattern for set collecting.

Keep this architecture:

Collection | Traders | ISO

Use Collection singular for the top tab.

Inside Collection, use a second-level navigation:

All Pins | Boards | Sets

This should replace the current horizontally scrolling Group By chips.

Do not show Character, Location, Year, Brand, Series etc. as permanent top-level chips.

ALL PINS

Default view when Collection opens.

Show every owned pin in the existing image-first pin grid.

Keep:

* current pin card design
* Search
* ●	Add
* one lightweight Filter/Sort control

All Pins must ALWAYS remain selectable.

The user must be able to navigate:

All Pins → Boards → Sets → All Pins

repeatedly without reloading or leaving the page.

Do not treat All Pins as an invisible/default state that disappears after another view is selected.

BOARDS

Boards are user-created ways to organise pins.

Reuse the existing Boards/custom Collections functionality and data.

Use the term:

Boards

not “My Collections” inside this area.

Examples:

* Favourite Pins
* Winnie the Pooh
* Halloween
* Disneyland Paris 2026
* Never Trade
* Main Pin Board

A pin should be able to appear in multiple Boards without creating duplicate ownership records.

Boards should appear as a visual grid using existing board/collection card components where possible.

Each Board card should show:

* representative pin previews
* board name
* pin count

Opening a Board should show its pins using the existing pin grid.

Provide clear navigation back to Boards.

Make Create Board easy to find from the Add action and/or Boards view.

SETS

Sets are different from Boards.

Boards = created and organised by the collector.

Sets = official/catalogue-driven groups organised by PinHunt.

Reuse the existing catalogue set data, set progress logic and Set Detail functionality.

The Sets view should show sets the collector has explicitly chosen to track.

Suggested structure:

My Sets

Optional lightweight filter:
In Progress | Completed

Each set card should show:

* set name
* useful representative pin previews
* owned / total count
* completion %
* completed state where appropriate

Example:

Wishables Shimmer 2026
12 / 16 · 75%

Ducks of Disney 2025
16 / 16 · Complete ✓

Do not make this look like a dashboard.

Keep imagery prominent.

TRACKING A SET

Users must have an obvious way to add/track an official set.

Use:

+ Add → Track a Set

Track a Set should open the existing catalogue/set search where possible.

Example:

Search sets…

Wishables Shimmer 2026
Ducks of Disney 2025
Princess Pastries 2024

Selecting a set should allow:

Track Set

Once tracked, calculate current completion automatically from the user’s existing owned pins.

For example, if the user already owns 7 pins from a 16-pin set, tracking it should immediately show:

7 / 16

Do not require the user to add those pins again.

Future owned pins from that set should automatically update progress.

Do not automatically track every set merely because the user owns one pin from it.

Owning a pin from a set and actively tracking a set are separate concepts.

If a small schema change is genuinely required for tracked sets, keep it minimal and reuse existing set/catalogue IDs.

SET DETAIL

Opening a set should reuse the existing Set Detail experience and show the full official set.

Desired behaviour:

* owned pins = full colour
* missing pins = muted/greyed
* duplicate ownership = quantity indicator such as ×2
* ISO missing pins = subtle ISO indicator
* set completion %
* collected / total count

For a missing pin support existing actions such as:

* Add to ISO
* Find Trade

For an owned pin:

* open existing Pin Detail

Preserve any existing set completion animation/achievement functionality.

TERMINOLOGY

Use this terminology consistently:

Collection = overall owned-pin area
All Pins = every pin owned
Boards = collector-created organisation
Sets = official catalogue-driven sets the user chooses to track
Traders = owned pins available for trade
ISO = pins the collector wants

Character, year, location, brand and series are filters/search metadata, not primary navigation.
